# Port Scanner Analyzer

A Python script to scan and analyze open ports on a given IP address range.

## Features
- Scans a specified range of ports on a given IP address.
- Saves the scan results to a text file.
- Generates a visual representation of the scan results and saves it as a PNG file.

## Usage
To run the script:

```bash
python3 port_scanner.py <IP_ADDRESS> -p <PORT_RANGE>
